# 状态操作测试范围与剩余条件

当前 PC 全候选的新增实测与恢复限制见 [扩展验收](pc-web-complete-acceptance.md)：本轮实际执行读取和受控写入，并保留招募取消失败及游戏预约未取消的事实。

本页先列当前 PC 网页状态操作，再保留历史 App 记录。两个范围分别统计；历史 App 的主帖清理限制仍保留，不能被 PC 回复清理结果覆盖。

本轮独立 HTTP 请求、刷新后回读与历史执行方式的区别见 [直连专题](pc-web-direct-http.md)。

## 当前 PC 状态操作

| 能力 | 已验收范围 | 尚未覆盖 |
| --- | --- | --- |
| 点赞/取消点赞 | 帖子与普通回复分别读取基线、变化并恢复 | 楼中楼点赞未单独测试 |
| 普通回复、楼中楼及本人删除 | 多轮创建后核对新编号、作者和标记；楼中楼先删子后删父，均有清理回查 | 只覆盖各轮受控新内容及所检查列表 |
| 收藏/取消收藏 | 未收藏基线下添加、回查变化、取消后恢复 | GET/POST 取消均已补测；其他收藏状态枚举未覆盖 |
| 用户关注/取消关注 | 两受控账号的关注变化与移除粉丝均有双端回查和原关系恢复 | 只覆盖单个受控目标 |
| 主帖及本人删除 | 已独立 HTTP 创建并清理；作者、标题和 first_floor 正文匹配，删除后两个预验证入口返回 4 | 不证明底层存储、所有协议或历史 App 主帖已清除 |

| 隐私、黑名单、简介与徽章 | 切换后回读并恢复原值；昵称保持不变 | 不包含昵称冷却与所有隐私枚举 |
| 图片与智能标题 | PNG 上传返回引用，图片回复回读并删除，标题返回 5 条非空结果 | 头像 300003、图片列表 4444，其他媒体类型未形成完整验收 |
| 预约与招募 | 预约两种方法首次成功，真实招募报名和即时资格成功 | 2 项预约保留；招募取消两次 990000，原报名状态未恢复 |
| 吧务管理 | 账号没有实际吧务角色 | 用户确认没有吧务账号；本人测试内容删除已有独立证据 |

有效请求组合和清理判据见 [PC 基础功能](pc-web-basic-functions.md) 及 [签到与主帖](pc-web-sign-search-publish.md)，完整候选状态见 [PC CSV](pc-web-api-coverage.csv)。现有网页会话、指定帖子和测试吧足够继续普通功能；额外样本只按具体 PC 功能申请，见 [验收资源](acceptance.md)。

| 能力 | 已观察结果 | 尚未覆盖的边界 |

本人新主帖只创建了一条，位于用户链接对应的“测试吧（名称已移除）”。具体编号和标记留在本机忽略目录；未继续创建新内容。名称包含 bawu 的本人删除接口不等同于管理员操作。

| 剩余范围 | 具体缺项 |
| --- | --- |
| 吧务管理 | 用户明确不测；保留既有观测并列为 excluded-by-user |
| 单聊、SDK 普通群聊 | 双向收发、回读、本人撤回及退出已完成；见 [IM 实测](im-validation.md)。公开聊天室、直播群发等仍需各自对象和协议 |
| 语音、部分视频、投票、活动和直播 | 缺少对应有效内容、房间或活动样本；图片代理通过不等同于这些能力通过 |
| 其他状态操作 | 各自的请求参数、有效目标或恢复步骤尚未建立；不能根据路径名执行 |
| 订单、购买、支付、账号清空或关闭 | 缺少隔离订单、沙箱或专用账号；未用真实扣款或清空账号来探测 |
| 遥测和日志状态 | 已有匿名空请求返回；真实事件字段、处理语义与后台可观测验收仍未完成 |

现有线上读取计划全部执行过，仍不表示全部候选可用。对象级断言、负对照、业务错误和未执行操作在当前清单中分别保留，原始响应和账号配置不进入 Git。

后续 249 次请求及业务验收缺项见 [补测报告](supplemental-validation.md)。该补测阶段的 184 条候选只有匿名诊断，后续 App 汇总为 176 条；其中请求构造分析尚未完成的项目明确保留，不写成服务端限制。
