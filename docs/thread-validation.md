## 复测

在仓库根目录使用 Node.js 24+，不需要登录态或额外 npm 依赖：

```powershell
node scripts/verify-thread.mjs --live --thread $env:TIEBA_TEST_THREAD
```

也可以把 `--thread` 后的值换成十进制帖子编号。脚本只接受官方帖子 URL 或正 int64 编号；输出写入 `.local/thread-<编号>-verification.json`，原始响应使用独立文件名，不覆盖首批公开样本。缺少楼中楼样本、响应不匹配、请求或解码失败时，不判为整轮通过。公开帖子可能被编辑、删除或限制访问，复测需按实际返回判断。
