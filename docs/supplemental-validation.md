## 小尾巴与关注列表开关

小尾巴使用已提取的 `AddTail`、`UpdateTail`、`SetTail`、`DeleteTail` 和 `GetTails` 契约。它们的响应封装为 `data=1, error=2`，不同于部分其他接口。`tailId` 仅取本次创建并回查确认的对象，没有使用已有用户对象来测试删除。

| 操作 | 实际结果与验收 |
| --- | --- |
| 新增、编辑、删除小尾巴 | 两轮分别创建一个样本；创建后的编号与内容、编辑后的内容均匹配，删除后样本消失 |
| 启用、停用样本 | 两次均返回 3110002，明确提示“对不起，您不是贴吧会员！”；没有状态变化成功的证据 |
| 清理 | 两个样本均已删除，列表内容及选择状态与各自基线完全一致 |
| 关注列表开关 | 原值 2 → 1 → 2，写入、回读及恢复均确认；完整公开/私密枚举含义未另行验证 |

首次小尾巴新增返回 300000 参数错误，列表未变。随后从 APK 的资源 `0x7f0f184a` 取得 `fontKeyName=Helvetica Neue`，使用返回的默认颜色格式并缩短测试内容后成功。重试同时改变了字体和内容，不能将第一次错误单独归因于字体。

关注列表开关最初只做读取预检：0/1 枚举假设与实际返回值 2 不符，未发出写入。保留这次预检，随后以实际读取值为恢复基线完成变化与恢复。此流程没有增删关注关系。

先前测试主帖的首楼编号仍可读取、SDK 空群元数据仍保留以及类型 22 记录含义未确认的限制，仍分别见 [当前报告](remaining-validation.md) 和 [IM 报告](im-validation.md)；本阶段的清理成功不能扩大到那些对象。

## 复测与离线重建

在仓库根目录执行：

```powershell
node scripts/verify-anonymous-boundaries.mjs --live --limit 1
node scripts/build-current-coverage.mjs
node --test tests/*.test.mjs
```

匿名工具不读取账号配置，固定请求生产主机，正文为空，不自动跟随重定向；每次上限 12 秒、1 MiB。省略 `--limit` 可复测冻结清单中目前仍在范围内的 201 项匿名边界，已明确排除的吧务不重测。每轮原始响应和新报告以随机运行编号写入 `.local/`，不覆盖冻结证据。本阶段公开入口实际执行了 1 项；202 项原始诊断由先前保存的同类工具完成。

`build-current-coverage.mjs` 只依赖仓库中的脱敏证据，可以在新克隆中离线重建当前报告。`build-supplemental-validation.mjs` 校验并投影本机冻结响应、受控对象及清理记录，需原始忽略文件；新克隆不能凭公开摘要重建私人历史响应。新增线上结果需先审核、脱敏，再明确纳入统计，不能覆盖旧观察。
