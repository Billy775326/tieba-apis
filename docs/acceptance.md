## 优先申请的资源

优先提供一套可操作的 Android 测试环境，已有两个账号可继续复用，无需增加普通账号或发送密码、Cookie、BDUSS。

| 优先级 | 资源 | 用途与必要范围 |
| --- | --- | --- |
| 1 | 本机可操作的安卓模拟器，或可通过 USB 调试连接的备用安卓手机 | 安装目标 APK，观察实际流程并生成有效业务对象；先提供设备/模拟器名称和连接方式，不预设需要 root |
| 2 | 有效业务样本链接或 App 入口 | 含语音的帖子、AI 答案帖/机器人入口、有非空官方菜单的吧及官方会话；资源可分批提供，公共链接先做读取验收 |
| 3 | 可管理的活动、投票、直播/聊天室测试对象 | 用于对应专用接口；普通帖子、普通私信或 SDK 群聊不能替代这些对象 |
| 按需 | 已有对应会员权限的专用测试账号，使用扫码登录 | 只为验证明确返回会员限制的正向分支；无需为测试购买会员 |
| 特殊项目 | 官方支付沙箱/隔离订单、允许销毁的独立测试账号 | 分别用于支付和账号清空流程；没有这些资源时保留未验收，不能使用正常账号或真实付款替代 |

先提供第 1 项即可，其他样本可后补。如果仍只有 APK 和网页登录，可以先给任一有效样本链接，继续做读取和协议分析。吧务仍按原要求排除，不申请吧务账号。
